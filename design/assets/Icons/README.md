# Icons

24×24 outlined icons, 1.75px stroke, round caps and joins, drawn in `ink` (#1c2620) for light contexts. In code use the `Icon` component instead, which takes the text color.

- `posture.svg` — Posture reminders.
- `move.svg` — Walk and move breaks.
- `eyes.svg` — Eye rest (20-20-20).
- `water.svg` — Water reminders.
- `stretch.svg` — Stretch breaks.
- `snooze.svg` — Snooze and paused states.
