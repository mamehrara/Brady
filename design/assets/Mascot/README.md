# Mascot

Brady in the hanging pose, 96×96, claws at the top edge. Full color; the colors are the `brady-*` tokens.

- `brady-hang-awake.svg` — A new reminder.
- `brady-hang-cheer.svg` — After Done.
- `brady-hang-sleepy.svg` — After Snooze, and while reminders are paused.

Place it so the top 5px (the claws) overlap the edge he hangs from.
